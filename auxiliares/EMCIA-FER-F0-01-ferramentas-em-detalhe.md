## 1. Objetivo
Detalhar cada instrumento selecionado para esta fase, de modo que um engenheiro que não participou da seleção saiba quando aplicá-lo, como aplicá-lo e quando parar. Este documento é auxiliar do quadro de ferramentas EMCIA-FER-01, que registra a seleção; aqui está a aplicação.

## 2. Escopo e aplicação
Aplica-se aos 7 instrumentos selecionados para a fase F0 — Enquadramento. A sigla é a mesma do quadro e permanece estável ainda que o instrumento seja reposicionado.

Fase de alta rotatividade e baixa consequência: os instrumentos são leves e a maior parte da saída é declarada. O que a fase produz é delimitação e nível, nunca diagnóstico.

## 3. Fichas
O campo de erro comum registra a falha observada na aplicação do instrumento, e não a sua limitação teórica. É o campo de maior valor para quem aplica pela primeira vez.

### NEG-01 · 5W2H

| Campo | Especificação |
| :--- | :--- |
| **Para que serve** | Delimitar a dor em sete dimensões, para que o problema deixe de ser enunciado como categoria e passe a ser um evento situado. |
| **Quando aplicar** | Primeira sessão com o patrocinador, antes de qualquer pergunta sobre solução. |
| **Como aplicar** | 1. Pedir o relato livre antes de abrir o quadro.<br>2. Preencher cada campo com palavras do relato, e não com paráfrase.<br>3. Devolver o quadro preenchido e corrigir com o interlocutor. |
| **Insumo e saída** | Relato do patrocinador → Quadro com os sete campos e marca de procedência |
| **Erro comum** | Preencher “por quê” com a solução pretendida em vez da consequência do problema. |
| **Encerramento** | Os sete campos preenchidos e confirmados pelo interlocutor. |
| **Exigida em** | Todos |

### NEG-02 · Cinco porquês

| Campo | Especificação |
| :--- | :--- |
| **Para que serve** | Separar sintoma de causa, evitando que o engajamento automatize o efeito e deixe a origem intacta. |
| **Quando aplicar** | Logo após o 5W2H, na mesma sessão. |
| **Como aplicar** | 1. Partir do efeito registrado no campo “o quê”.<br>2. A cada resposta, perguntar o que a sustenta.<br>3. Parar quando a resposta seguinte sair do alcance da organização. |
| **Insumo e saída** | Dor estruturada → Cadeia causal, com procedência por elo |
| **Erro comum** | Aceitar a primeira causa oferecida, que costuma ser a que o interlocutor já defendia antes da conversa. |
| **Encerramento** | Cadeia registrada, com o elo final identificado como dentro ou fora do alcance. |
| **Exigida em** | Todos |

### NEG-03 · Diagrama de causa e efeito

| Campo | Especificação |
| :--- | :--- |
| **Para que serve** | Distribuir as causas entre pessoas, processo, tecnologia e política, impedindo que todas recaiam na categoria que o interlocutor domina. |
| **Quando aplicar** | Quando os cinco porquês produzirem mais de uma cadeia. |
| **Como aplicar** | 1. Agrupar as causas levantadas por categoria.<br>2. Examinar a categoria vazia: costuma indicar ponto cego, e não ausência.<br>3. Marcar quais causas o engajamento alcança. |
| **Insumo e saída** | Cadeias causais → Causas categorizadas, com alcance marcado |
| **Erro comum** | Usar como dinâmica de reunião e não registrar o resultado. |
| **Encerramento** | Cada causa em uma categoria, com alcance declarado. |
| **Exigida em** | N2 e N3 |

### ADM-01 · Custo do problema

| Campo | Especificação |
| :--- | :--- |
| **Para que serve** | Converter a dor em valor anual, para que a priorização e o retorno tenham base numérica. |
| **Quando aplicar** | Depois de estabelecida a causa, ainda na Fase F0. |
| **Como aplicar** | 1. Escolher no máximo três componentes de custo.<br>2. Declarar a base de cálculo de cada um.<br>3. Marcar a procedência de cada número. |
| **Insumo e saída** | Volumes e tempos informados → Custo anual, com premissas expostas |
| **Erro comum** | Somar componentes que se sobrepõem, contando o mesmo tempo duas vezes. |
| **Encerramento** | Todo número com base de cálculo e procedência registradas. |
| **Exigida em** | Todos |

### ADM-02 · Objetivos SMART

| Campo | Especificação |
| :--- | :--- |
| **Para que serve** | Transformar intenção em enunciado verificável por terceiro. |
| **Quando aplicar** | Ao final do enquadramento, antes da decisão de prosseguir. |
| **Como aplicar** | 1. Fixar o indicador antes de fixar a meta.<br>2. Declarar a data em que será apurado.<br>3. Verificar se alguém saberia dizer, no prazo, se foi atingido. |
| **Insumo e saída** | Dor delimitada e custo estimado → Enunciado com indicador, valor e data |
| **Erro comum** | Objetivo cuja verificação depende de julgamento de quem o redigiu. |
| **Encerramento** | Enunciado que permite resposta binária na data declarada. |
| **Exigida em** | Todos |

### ADM-03 · Delimitação de escopo

| Campo | Especificação |
| :--- | :--- |
| **Para que serve** | Registrar o que fica de fora antes que a expectativa se forme. |
| **Quando aplicar** | Junto com o objetivo, na mesma sessão. |
| **Como aplicar** | 1. Listar o que está dentro.<br>2. Listar explicitamente o que está fora, sobretudo construção e implantação.<br>3. Obter confirmação do patrocinador sobre as duas listas. |
| **Insumo e saída** | Objetivo e trilha prevista → Duas listas confirmadas |
| **Erro comum** | Declarar apenas o que está dentro, deixando o resto por inferência. |
| **Encerramento** | As duas listas registradas e confirmadas. |
| **Exigida em** | Todos |

### ADM-04 · Instrumento de triagem em três eixos ★

| Campo | Especificação |
| :--- | :--- |
| **Para que serve** | Apurar o nível de complexidade que calibra a profundidade de todo o percurso. |
| **Quando aplicar** | Após o enquadramento e antes do passo 1. |
| **Como aplicar** | 1. Aplicar as nove perguntas sempre sobre o processo-alvo delimitado.<br>2. Registrar a resposta literal e quem respondeu cada item.<br>3. Apurar pelo maior eixo, nunca pela média. |
| **Insumo e saída** | Respostas da organização → Três somas e o nível declarado |
| **Erro comum** | Responder sobre a organização em geral, e não sobre o processo-alvo. |
| **Encerramento** | Nove respostas, três somas e nível registrado como declarado. |
| **Exigida em** | Todos |

---

## 4. Condição de aceite
Este artefato está pronto quando todo instrumento selecionado para a fase tem os sete campos preenchidos; quando o campo de encerramento permite verificar, sem consulta a terceiros, se a aplicação terminou; e quando o erro comum descreve falha de aplicação, e não limitação do instrumento.
